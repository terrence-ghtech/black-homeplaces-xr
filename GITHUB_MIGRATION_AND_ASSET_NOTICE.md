# GitHub Migration and Asset Notice

This repository must remain private.

Contributor media may not be redistributed publicly without authorization. Third-party Unity asset packs remain subject to their original licenses. Project source ownership is governed by the BCaT/GHTech agreement.

External exhibit URLs are runtime dependencies but are not hosted by this repository. Build outputs are not committed and must be regenerated locally.

Git LFS is required before cloning or contributing. Large binary media should not be repeatedly replaced unnecessarily because each changed LFS version consumes storage.

A clean clone should use Unity `6000.4.5f1`.

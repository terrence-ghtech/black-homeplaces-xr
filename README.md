# Black Homeplaces XR House

Unity project for the Black Homeplaces XR House experience.

## Project Details

- Unity version: `6000.4.5f1`
- Platforms: WebGL and Meta Quest/Android
- Canonical production project folders:
  - `Assets`
  - `Packages`
  - `ProjectSettings`

## Git LFS Required

Install Git LFS before cloning or contributing:

```sh
git lfs install
```

Clone using the private repository URL provided by the project owner:

```sh
git clone <PRIVATE_REPOSITORY_URL>
cd <REPOSITORY_FOLDER>
git lfs pull
```

Open the project with Unity `6000.4.5f1`. Using a mismatched Unity version can rewrite project metadata or package state.

## Repository Scope

This repository is private and contains licensed, contributor, and client material. Do not redistribute repository contents publicly without authorization.

`Library`, generated builds, APKs, WebGL output, caches, and other generated files are intentionally excluded from source control. Platform builds must be regenerated locally from the checked-in Unity project.

External exhibit links and services require internet access at runtime.
